# 🌳 Arbre Généalogique – Projet de Graphes & Algorithmes

Bienvenue dans ce projet académique passionnant mêlant **mathématiques discrètes**, **programmation** et **représentation visuelle** !  
Ce projet permet de créer dynamiquement un **arbre généalogique** en utilisant des **graphes orientés** et des **algorithmes de parcours** pour déterminer les liens familiaux entre les individus.

---

## 🧠 Objectif

Le but de ce projet est de :

- Représenter les **relations familiales** (parenté, descendance, fratrie) sous forme de **graphe**
- Utiliser des **algorithmes de parcours** (BFS, DFS) pour identifier et naviguer dans les liens familiaux
- Offrir une **interface utilisateur intuitive** pour créer, visualiser et explorer son **arbre généalogique**

---

## ⚙️ Technologies utilisées

- 💻 **JavaScript** — logique et algorithmes de parcours
- 🎨 **HTML / CSS** — structure et design de l'interface
- 🧩 **Graphes orientés** — pour modéliser les relations
- 🔍 **Algorithmes** — recherche de chemins familiaux, exploration des descendants, etc.

---

## 📸 Aperçu du projet

> L’utilisateur peut :
- Ajouter des membres à l’arbre
- Définir les relations (parent, enfant, etc.)
- Visualiser les liens entre individus
- Rechercher les liens entre deux personnes
- Explorer les ascendants ou descendants d’un membre


---

## 🛠️ Lancer le projet localement

Aucune installation compliquée nécessaire 🎉

1. Clone le dépôt :
```bash
git clone https://github.com/cngomc1/Arbre-Genealogique.git
```

2. Ouvre le fichier `index.html` dans ton navigateur préféré :
```bash
cd Arbre-Genealogique
start index.html
```

C’est tout ! Tu peux maintenant commencer à créer ton arbre.

| Fonction                      | Description |
|------------------------------|-------------|
| ➕ Ajouter un membre          | Entrée manuelle dans l’interface |
